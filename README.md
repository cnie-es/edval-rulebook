# NEL-DS Rulebook (Marco de Gobernanza)

Este repositorio contiene la fuente de la verdad para el **Marco de Gobernanza del Espacio de Datos de la Nueva Economía de la Lengua (NEL-DS)**.

**Autoridad:** Centro Nacional de Industrias del Español (CNIE).  
**Referencia del Proyecto:** Expediente 71-7-2.01-0004/2025.  
**Estado Actual:** `v1.0.0` (Borrador para Aprobación).

## 📂 Estructura del Repositorio

* **[`/docs`](./docs/):** Documentación normativa legible por humanos (Markdown).
    * [Capítulo 1: Disposiciones Generales](./docs/capitulo_1_general.md)
    * [Capítulo 2: Marco Legal](./docs/capitulo_2_legal.md)
    * [Capítulo 3: Marco Operativo](./docs/capitulo_3_operativo.md)
    * [Capítulo 4: Marco Técnico](./docs/capitulo_4_tecnico.md)
    * [Capítulo 5: Confianza y Anexos](./docs/capitulo_5_confianza_y_anexos.md)
* **[`/code`](./code/):** Definiciones legibles por máquina (Machine-readable policies).
    * Políticas de uso estándar en formato ODRL (JSON-LD).
* **[`/releases`](./releases/):** Versiones congeladas y firmadas en PDF.

## 🚀 Cómo contribuir
Las propuestas de modificación al Rulebook deben seguir el flujo de gobernanza establecido (ver [CONTRIBUTING.md](./CONTRIBUTING.md) para más detalles):
1.  Abrir una **Issue** describiendo el cambio regulatorio propuesto.
2.  Crear una **Pull Request** con la modificación sobre los archivos `.md`.
3.  El Comité de Dirección del NEL-DS revisará y aprobará (Merge) o rechazará la propuesta.
